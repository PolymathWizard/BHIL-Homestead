# Glossary

| Term | Meaning |
|---|---|
| 88x31 | The standard size, in pixels, of small link buttons on 1990s homepages |
| Asset policy | originals-only or archive-allowed; decides what images and sounds a build may use |
| Blinkie | A 150 by 20 pixel animated text strip from the profile era |
| Canon | The JSON files in `canon/` that every tool and document is generated from |
| CADRE | The BHIL pattern of one orchestrator over tool-isolated subagents |
| Drift gate | `scripts/verify_drift.py`, which fails on any hand edit to a derived artifact |
| Era spec card | `02-era-spec.json`: preset, year, canvas, palette, fonts, widgets, voice, motion, audio |
| Frameset | A page split into independently scrolling frames; emulated, never shipped |
| Hit counter | A visible visitor count, often odometer digits |
| Homesteader | A GeoCities member; the source of the framework's name |
| Lived-in detail | A sign that a site was used and maintained, such as a stale Last updated date |
| Marker | `<!-- hs:widget ID -->`, the comment that tells the lint which widget is present |
| Neighborhood | A GeoCities topic area that formed part of a page address, such as SiliconValley |
| Preset | One of six locked era specs, A to F |
| Safe Mode | The safety layer control that stops motion and sound and raises contrast |
| Shared borders | FrontPage regions (top, left, bottom) repeated on every page |
| Spacer GIF | A transparent 1x1 image stretched to create gaps |
| Still frame | `name-still.gif`, the first frame of an animation, swapped in by Safe Mode |
| Time capsule | A declared story that lets one build span eras |
| Top 8 | A profile's featured friends grid |
| Web-safe palette | The 216 colors made of 00, 33, 66, 99, CC, and FF per channel |
| Webbot | A FrontPage component recorded in source as a comment |
| Webring | A themed ring of sites linked by previous, next, and random links |
| WordArt | Stylized title text, here rendered by gifsmith in a pixel font |
