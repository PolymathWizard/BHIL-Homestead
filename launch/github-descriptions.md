# GitHub description options

Each option is checked by `scripts/validate.py` to stay at or under 350 characters.

## Option A (recommended): capability-first

```text
HOMESTEAD by BHIL: analyze any modern website and rebuild it as a 1998 GeoCities homepage, a 2001 FrontPage company site, or a 2007 MySpace profile. Six era presets, a component mapping table, an anachronism lint, a GIF flash audit, Safe Mode on every page, and a Claude Code agent team with a blind auditor. Stdlib Python.
```

Length: 323 characters.

## Option B: method-first

```text
Retro-web redesign engine. Survey a modern site, lock one era, map every component to its period equivalent, and build in real period markup with original generated GIFs and a safety layer. 40-point authenticity rubric, Claude Code subagents, P00 to P10 prompts. MIT and CC BY 4.0.
```

Length: 281 characters.

## Option C: outcome-first

```text
Turn any modern website into a convincing old-school site without the pastiche: one locked era, period markup that survives View Source, original assets with no borrowed GIFs or fonts, and Safe Mode for today's visitors. Process, tools, kits, and agents from Barry Hurd Intelligence Lab.
```

Length: 287 characters.

## Recommendation

Option A. It names the three eras people recognize instantly, which is what makes someone click, then proves depth with the toolchain list. Option B suits a technical audience browsing agent frameworks. Option C suits a design audience and reads best on a profile pin.

## Website field

Set the About panel website to https://barryhurd.com/project/BHIL-Homestead.html, the project page and scroll-through tour.
