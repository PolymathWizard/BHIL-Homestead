# LinkedIn launch variants

Three variants, each closing with the project page and repository addresses and the BHIL tagline. Attach `media/bhil-homestead-intro.gif` to whichever variant you post. Per BHIL storytelling practice they carry no statistics; the validator rejects digits other than era years.

## Variant 1: technical authority

```text
Most retro website redesigns fail the same way. They mix eras: glitter text from the profile years on a starry homepage from the dial-up years. Or they leak the present: web fonts, rounded corners, perfect gutters, copy that says get started.

So we built HOMESTEAD, an open framework for doing this properly.

It treats the old web as six dated presets, not one look. Each preset carries a canvas width, a palette, system fonts, required widgets, a voice, and a motion budget. A survey tool inventories the modern site. A mapping table translates every component: testimonials become guestbook entries in 1998, a customer quotes page in 2001, and comments in 2007. Builds are written in real period markup, linted for anachronisms, and audited for flash safety.

Then a separate agent grades the work. It cannot write files and never sees the builder's reasoning, so the build never grades itself.

Every page ships with Safe Mode: one control that stops motion and sound and raises contrast. Every image and sound is generated from scratch, so nothing borrowed rides along.

Open source, standard library Python, Claude Code agents included.

Human-Directed. AI-Enabled. Commercially Tested.
```

## Variant 2: inquiry-driving

```text
What would your website have looked like in 1998?

Not a filter. The real thing: a homepage in a themed neighborhood, a hit counter, a guestbook where your testimonials used to be, a webring instead of social icons. Or the 2001 version, with shared borders, beveled buttons, and Welcome to our Web site! Or the 2007 profile, where your best customers sit in the Top Eight.

HOMESTEAD is the process we built to answer that question rigorously for any brand. It surveys your current site, locks one era, maps every component, and builds pages that survive View Source, with a Safe Mode so nobody gets a headache.

It turns out to be a sharp mirror. Translating a modern site into an older vocabulary shows exactly which parts of it are substance and which are fashion.

If you want to see your brand in a past life for a launch, an anniversary, or a team offsite, send me a message.
```

## Variant 3: peer builder ship post

```text
Shipped: HOMESTEAD.

It started as a weekend question and turned into a full framework with canon, tools, kits, and an agent team. A few things I enjoyed building:

A GIF encoder and decoder in plain Python, so every badge, button, counter, and glitter name is drawn from a hand-entered pixel font. No borrowed clip art.

An anachronism lint that knows flexbox never existed on a dial-up homepage and that glitter belongs to the profile era, not the starry-background era.
```
