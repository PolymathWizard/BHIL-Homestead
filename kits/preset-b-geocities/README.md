# Kit: preset B, GeoCities homepage

A working starter for the GeoCities, Angelfire, and Tripod personal homepage era. Every image and sound in this folder is generated by `tools/gifsmith.py` from [recipe.json](recipe.json), so the kit carries no third-party assets.

| File | Purpose |
|---|---|
| [index.html](index.html) | Home page with title, marquee, construction sign, What's New, Cool Links, webring, hit counter, badges, and footer |
| [guestbook.html](guestbook.html) | Sign my guestbook form plus past entries, where modern testimonials land |
| [text-only.html](text-only.html) | Plain version for accessibility, linked from every page |
| `homestead-safe.css`, `homestead-safe.js` | Safety layer copies, drift-checked against `kits/safety-layer/` |
| `images/`, `audio/` | Generated assets |

## How to use it

1. Open an engagement with `python3 tools/scaffold.py new <slug> --target <url> --preset B`. The kit is copied into `05-build/`.
2. Replace every `[bracketed]` value with mapped content from `03-mapping.md` and `03-copy-deck.md`.
3. Regenerate the title with `python3 tools/gifsmith.py one wordart 05-build/images/title.gif --params '{"text": "YOUR NAME", "scale": 5, "shadow": "#660066", "outline": "#000000"}'`.
4. Keep every `<!-- hs:widget ... -->` marker next to its widget. The lint uses them to check the required set and to catch era mixing.
5. Run `python3 tools/era_lint.py 05-build --preset B` after every edit.

## Era notes

- Canvas is 600 px for 1996 to 1998. Use 760 px for a 1999 or 2000 page and update the era spec.
- Flat colors stay on the web-safe cube. The lint warns on anything else.
- Motion budget is four moving items per page: here the marquee, the construction sign, the NEW graphic, and the Email me envelope.
- The commented `bgsound` line is there for View Source. The music only plays when the visitor clicks the music badge.
